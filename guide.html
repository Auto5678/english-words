二、每天怎么学？五步走！

第1步 第2步 第3步 第4步 第5步 ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │ 打开 │ │ 点击 │ │ 学新词│ │ 做三 │ │ 读短 │ │ 今日 │ ──→ │ 开始 │ ──→ │ +跟读│ ──→ │ 项测试│ ──→ │ 文 │ │ 页面 │ │ 学习 │ │ │ │ │ │ │ └──────┘ └──────┘ └──────┘ └──────┘ └──────┘

第 1 步：打开“今日”页

你会看到今天的任务：

┌─────────────────────────────┐ │ 你好，小明 │ │ 积分 156 等级 2 │ ├─────────────────────────────┤ │ 今日任务 │ │ 新词：10 个（今日已学 3） │ │ 到期复习：5 个 │ │ │ │ ┌───────────────────────┐ │ │ │ 开始学习 │ │ │ └───────────────────────┘ │ └─────────────────────────────┘

新词就是今天第一次见的单词，复习是以前学过、今天到了该复习日子的单词。

第 2 步：点“开始学习”

第 3 步：学新词 + 跟读

每个新词会先亮出来给你看：

┌─────────────────────────────┐ │ 新词学习（3/10） │ │ │ │ morning │ ← 大大的英文单词 │ n. │ ← 词性 │ 早晨；上午 │ ← 中文意思 │ │ │ I run in the morning. │ ← 例句（目标词有颜色） │ │ │ ┌─────────┐ ┌──────────┐ │ │ │ 🎤 跟读 │ │ 下一个 → │ │ │ └─────────┘ └──────────┘ │ └─────────────────────────────┘

看懂了，就点“下一个”。想练发音，就点“跟读”（第三节详细教）。

第 4 步：做三项测试

新词全部学完后，进入测试环节。每个单词要过三关：

第一关 第二关 第三关 ┌──────┐ ┌──────┐ ┌──────┐ │ 认读 │ ──→ │ 拼写 │ ──→ │ 听写 │ │看英文 │ │看中文 │ │听发音│ │选中文 │ │拼英文 │ │拼英文│ └──────┘ └──────┘ └──────┘
  • 认读：屏幕上出现英文单词，从 4 个中文里选出正确的意思。
  • 拼写：给你中文意思，你在输入框里打出英文单词，点提交。
  • 听写：先听发音（点“再听一次”可以重复听），再拼写出来。输入框上方会显示“单词1”“单词2”，告诉你进度。
💡 小贴士：拼错不可怕！错过的词第二天会再来找你复习，多见几次就记住了。

第 5 步：读短文

测试全部完成，恭喜你获得 +10 积分！然后去底栏点“阅读”，把今天学的单词放进小故事里再巩固一遍。

三、跟读怎么玩？拿高分秘籍

跟读就像跟老师读课文。点“🎤 跟读”后：

  1. 先听示范读音（系统自动播放）
  2. “滴”一声后开始录音，大声读出来！（最多 6 秒）
  3. 马上看到你的分数：0 ~ 100 分
┌─────────────────────────────┐ │ 第 2 次尝试 │ │ │ │ 85 基本正确，可放慢再读 │ │ │ │ 识别文本：morning │ │ │ │ ▶ 播放第 1 次录音 62分 │ ← 每次录音都能回放！ │ ▶ 播放第 2 次录音 85分 │ 听听自己读得怎么样 │ │ │ 已保存评分：85 │ └─────────────────────────────┘

分数是什么意思？

分数含义建议
90 分以上发音清晰太棒了，保持！
75 ~ 89 分基本正确放慢一点再读一遍
60 ~ 74 分有点差距再听两遍示范，逐字跟
60 分以下需要重听先认真听示范，再试一次

拿高分三个诀窍：

  1. 环境安静一点，离平板近一点。
  2. 可以多试几次！每次的录音都留着，可以回放对比——听听第 1 次和第 3 次的差别，进步听得见。
  3. 读得慢没关系，读清楚最重要。
⚠️ 注意：跟读不挣积分（不然一直对着麦克风喊就刷分啦），但跟读低于 70 分的词会出现在报告的“重点强化”里，多练几次把它消灭掉！

四、积分攻略（重点！）

挣分渠道一览

做什么得多少说明
学一个新词+2每天 10 个新词 = 20 分
认读答对+1每个词每天第一次答对才有分
拼写答对+2同上
听写答对+3三关里最高！
完成今日任务+10每天一次，全做完就有
读今日短文（对 60% 以上）+5每天一次
周六读周文章（对 60% 以上）+10只有周六有，别错过！

算一笔账：认真学一天能挣多少？

10 个新词全部答对： 新词 10 × 2 = 20 分 认读 10 × 1 = 10 分 拼写 10 × 2 = 20 分 听写 10 × 3 = 30 分 完成任务 10 分 短文练习 5 分 ────────────────────── 合计 95 分 ！

再加复习词答对的分，一天上百分不是梦。一个星期就能换小零食（150 分），坚持两周能换周末加半小时游戏（200 分）。

升级规则

等级 = 积分 ÷ 100 + 1 0 ~ 99 分 → 1 级 100 ~ 199 分 → 2 级 200 ~ 299 分 → 3 级 ……以此类推

每攒 100 分升一级！不过要注意：换奖励花掉积分后，等级会跟着降回去。想保级的话，先攒着；想换的，痛痛快快换——学习挣的分随时能再挣回来。

怎么换奖励？

┌─────────────────────────────┐ │ 我的积分 │ │ 当前积分 156 等级 2 │ ├─────────────────────────────┤ │ 可兑换奖励 │ │ 自选小零食 150分 [兑换] │ ← 积分够了按钮才能点 │ 周末游戏+30分钟 200分 [兑换] │ ├─────────────────────────────┤ │ 兑换记录 │ │ 自选小零食 [待确认] │ └─────────────────────────────┘
  1. 在积分页找到想要的奖励，点“兑换”。
  2. 系统会告诉家长你申请了（状态显示“待确认”）。
  3. 拿着平板去找家长确认——家长点确认后积分才扣、奖励才生效！

奖励有每周/每月次数限制，点不了就说明这周期换满了，下周再来。

五、阅读页：把单词放进故事里

┌─────────────────────────────┐ │ 📄 今日短文：My Day at School│ │ │ │ I get up at six thirty │ │ in the morning… │ ← 有颜色的词是今天学的 │ │ │ [🔊 朗读全文] [开始阅读练习] │ └─────────────────────────────┘
  • 有颜色的词就是你今天/本周学的单词，读的时候多留意它们。
  • 点“朗读全文”可以听整篇。
  • 点“开始阅读练习”做 5 道选择题，对 3 题以上（60%）就有积分。
  • 周六会出现一篇更长的“本周中篇文章”，分值更高（+10），只有周六能做！

六、报告页：看看自己多棒

点底栏“报告”，能看到：

  • 周报：这周学了多少新词、认读/拼写/听写的正确率。
  • 月报：这个月的总成绩、跟上月比是进步还是退步、跟读平均分、学习天数。
  • 重点强化单词：这里列出你最需要加强的词（错得多、跟读分低），每天优先搞定它们。
  • 每日错误明细：哪天、哪个词、错在哪一关、当时写了什么，一目了然。
📊 每月建议把报告给家长看一眼——让他们看到正确率升高的曲线，谈奖励的时候更有底气。报告还能导出成 Word 或 PDF 文件（点报告页右上角的按钮），想打印出来贴墙上也行！

七、遇到问题怎么办？

❓ 点了跟读没反应 / 提示不支持
  • 检查平板麦克风权限有没有开（浏览器会弹窗问“允许使用麦克风吗”，要点允许）。
  • 用 Chrome 或 Edge 浏览器打开，其他浏览器可能不支持。
  • 还不行就先跳过跟读，不影响其他学习。
❓ 录音放不出来
  • 先播放示范读音试试，如果示范也没声，检查平板音量。
  • 直接双击文件打开时，有些浏览器会限制播放录音。请家长帮忙用“本地服务”方式打开（比如在命令行运行 npx serve），就能正常录音回放。
❓ 密码忘了 / 想换账号
  • 切换学生、进家长区都要家长密码。忘了就找家长（初始密码是家长设置的 1234，改过的话只有家长知道）。
❓ 学习数据会丢吗？
  • 数据保存在这台平板的这个浏览器里。换浏览器、换设备、清除浏览器数据，进度就没了！ 所以：
  • 固定用同一个浏览器打开。
  • 让家长定期在“家长区 → 数据备份”里导出备份文件。
❓ 今天没有新词了？
  • 说明勾选范围的词都学完啦，等复习词到期会再出现。请家长在“家长区 → 背诵范围”勾选更多学年，或添加新单词。
❓ 奖励点“兑换”点不动？
  • 看按钮上的字：写“积分不足”就继续攒；写“本周已达上限”就下周再来。
